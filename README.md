# Central de Projetos
Orquestração de todos os projetos: Kanban + calendário único.
- `index.html` — dashboard (abra no navegador)
- `data.js` — projetos e tarefas (fonte única)
- `projetos/` — pasta de cada projeto

Fluxo: adicionar um projeto → classificar categoria → criar tarefas/recorrências → aparece no dashboard.
